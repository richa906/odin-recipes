# odin-recipes
A simple and delicious recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## About This Project

This project helped me understand and apply fundamental HTML concepts, such as:
- Structuring content using semantic HTML
- Creating links between pages
- Using lists and images effectively
- Creating a functional multi-page website

Through this project, I’ve learned how to:
- Organize files in a proper directory structure
- Use relative paths for internal links and images
- Work with Git and GitHub to version control my work
- Publish a website using GitHub Pages
## Recipes Included

- White Sauce Pasta
- Oreo Mug Cake
- Peri Peri Fries

Each recipe page features an image, a short description, ingredients, and a step-by-step guide.
